Proyecto: Análisis de IPS en Colombia

Proyecto enfocado en el análisis de datos del sistema de salud en Colombia utilizando SQL. Se trabajó en la limpieza, transformación y análisis de datos para generar insights relevantes sobre cobertura y distribución de IPS.

Enfoque del análisis

  • Consultas SQL para extracción de datos
  • Construcción de métricas clave
  • Análisis exploratorio
  • Optimización de consultas
