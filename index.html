01 · Problema de negocio

Preguntas que este
proyecto responde

P.01

¿Cuál es la densidad real de IPS por municipio ajustada por población?

Cobertura sanitaria calculada sobre proyecciones DANE oficiales, normalizada a 100.000 habitantes.

P.02

¿Qué prestadores presentan alertas regulatorias por vencimiento?

Clasificación de riesgo en tres estados: vigente, próxima a vencer (≤ 90 días) y vencida.

P.03

¿Cómo se distribuyen las IPS por naturaleza jurídica y antigüedad?

Análisis de distribución público vs. privado e institucionalidad histórica por departamento.

P.04

¿Dónde existen brechas territoriales en infraestructura sanitaria?

Identificación de municipios con cobertura crítica como insumo para decisiones de política pública.

02 · Metodología

Pipeline ETL implementado

01

Extracción

Carga masiva desde CSV

Importación del dataset REPS con LOAD DATA INFILE. Manejo explícito de nulos, separadores y campos opcionales mediante variables intermedias @campo para control antes de inserción.

LOAD DATA INFILE 'mi_data_ips.csv' INTO TABLE ips_raw FIELDS TERMINATED BY ',' ENCLOSED BY '"' LINES TERMINATED BY '\n' IGNORE 1 ROWS (@col1, @col2, @fecha_raw, @cod_mpio) SET nombre = NULLIF(TRIM(@col1), ''), cod_municipio = NULLIF(TRIM(@cod_mpio), '');
02

Transformación

Limpieza y tipado robusto

Conversión robusta de fechas con múltiples formatos, normalización de tipos numéricos y control de calidad post-carga mediante conteo de campos críticos.

UPDATE ips_raw SET fecha_habilitacion = STR_TO_DATE(fecha_raw, '%d/%m/%Y'), cod_municipio = NULLIF(TRIM(cod_municipio), ''), antiguedad_anos = TIMESTAMPDIFF(YEAR, fecha_habilitacion, CURDATE()); -- Control de calidad post-carga SELECT COUNT(*) AS total, SUM(fecha_habilitacion IS NULL) AS fechas_nulas FROM ips_raw;
03

Normalización geográfica

Claves de unión entre REPS y DANE

Componente crítico del pipeline: creación de claves normalizadas mediante remoción de tildes, normalización de mayúsculas y reemplazo de espacios para garantizar JOINs confiables entre la tabla de IPS y los datos de población del DANE.

UPDATE ips_clean SET municipio_key = UPPER( REPLACE( CONVERT(municipio USING ascii), ' ', '_' ) ); -- JOIN confiable entre REPS y población DANE SELECT i.municipio, p.poblacion FROM ips_clean i JOIN poblacion_dane p ON i.municipio_key = p.municipio_key;
04

Capa semántica

Vistas analíticas para Power BI

Vistas reutilizables para consumo directo en herramientas BI. Separación clara entre definición de vistas (DDL) y capa de consumo (consultas). Métricas calculadas: cobertura por 100.000 hab., naturaleza jurídica, riesgo regulatorio.

CREATE VIEW v_cobertura_municipal AS SELECT i.municipio, i.departamento, COUNT(*) AS total_ips, p.poblacion, ROUND(COUNT(*) * 100000.0 / p.poblacion, 2) AS ips_por_100k FROM ips_clean i JOIN poblacion_dane p USING(municipio_key) GROUP BY i.municipio, i.departamento, p.poblacion;
